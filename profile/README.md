## ⚙️ Overview

The **Gunfire Reborn Trainer** is designed for fast access and full modular control. It operates as an overlay menu, offering toggles for health, energy, movement speed, and weapon power — all adjustable mid-run without pausing.

It’s an essential tool for players who want to test class synergies, practice boss phases, or enjoy stress-free gameplay while experimenting with loadouts.

> [!IMPORTANT]
> The trainer is **100% offline safe** and does not alter core game files. It uses temporary memory edits that reset when you close the game.

## ⚡ Setup & Launch

1. Download and extract the trainer files to your **Gunfire Reborn** folder.
2. Run `GunfireTrainer.exe` **as Administrator**.
3. Wait for confirmation:

   ```
   [✔] Gunfire Reborn detected. Trainer loaded successfully.
   ```
4. Press **F8** to open the in-game overlay.
5. Use hotkeys to activate features:

| Action           | Hotkey |
| ---------------- | ------ |
| Toggle Menu      | F8     |
| Infinite Ammo    | F1     |
| God Mode         | F2     |
| Instant Cooldown | F3     |
| Add Soul Essence | F4     |
| Speed Boost      | F5     |
| Reset Defaults   | F10    |

## 🧠 Advanced Configuration

Create a `.ini` file for your preferred presets:

```ini
[Combat]
InfiniteAmmo=True
GodMode=False
DamageMultiplier=2.0

[Skill]
CooldownReset=True
EnergyLock=False

[Player]
MoveSpeed=1.75
JumpBoost=True
```

Place it in the same folder as the trainer (`config.ini`), and it will auto-load each time.

## ❓ FAQ

**Q1: Is the trainer safe to use?**
✅ Yes. It only edits runtime memory, no file injection or permanent modifications.

**Q2: Can I use it in online multiplayer?**
❌ No. It’s strictly for offline play. Online sessions are not supported or permitted.

**Q3: My overlay doesn’t show — what should I do?**
Switch your graphics to **DirectX 11** and relaunch with admin privileges.

**Q4: Does this affect achievements?**
No. Steam achievements remain unaffected unless you disable overlay permissions.

**Q5: How do I restore default gameplay?**
Press **F10** or close the trainer — all active scripts will unload automatically.
